Dealer Onboarding

How access would work

Dealer pricing remains protected because access is approved internally before an account is activated.

1

Apply

Company submits a Become a Dealer request.

2

Review

Plymovent reviews and approves the application.

3

Assign Pricing

Dealer is assigned A-Level or B-Level pricing.

4

Activate

Dealer account is created and login access is activated.

5

Use Portal

Dealer views pricing, downloads PDFs, and submits quote requests.

Quote Request

Need pricing for a customer or project?

Dealers can submit a request with the product, quantity, project information, and any additional notes. The request can be routed to the appropriate Plymovent team member for follow-up.

✓
Simple form, no formal quote generation required in Phase 1.
✓
Request can include one or multiple products.
✓
Internal notification can be emailed to the responsible sales contact.
